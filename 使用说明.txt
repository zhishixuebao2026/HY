花园：超限算力战争 —— 卡牌游戏
====================================

本压缩包包含「花园」系列设定的完整网页卡牌游戏，四个入口（建议首次游玩从「序章」开始）：
  · 序章·教学（7 课循序渐进，手把手带你学会所有机制）
  · 构筑对战（vs AI）
  · 超限阶梯爬塔（12 层）
  · 卡牌图鉴（72 张卡 / 13 个超限层级）

【怎么打开】
方式一（最推荐，零依赖）：
  直接双击本包里的「garden-standalone.html」
  —— 所有代码与插画已内嵌，无需联网、无需服务器、无需子目录。

方式二（源码/开发版）：
  用本地服务器打开，例如在本目录运行：
    python3 -m http.server 8080
  然后浏览器访问 http://localhost:8080
  （多文件版依赖子目录，不能直接 file:// 双击，否则图片会不显示）

【如果双击 html 仍打不开】
  · 请确认用浏览器（Chrome / Edge / Firefox）打开，而不是微信/手机自带预览
  · 检查解压是否完整：garden-standalone.html 应为约 5MB 的单文件（内嵌首页主视觉、4 张页头横幅与 30 张卡牌插画）
  · 某些手机系统限制本地 html，建议先在电脑上解压后用桌面浏览器打开

【文件说明】
  garden-standalone.html   自包含单文件版（双击即用，推荐）
  index.html               多文件版入口
  js/ css/ assets/         多文件版源码与素材
  build.js                 独立版构建脚本（node build.js 重新生成 standalone）

【爬塔进度会保存吗？会】
  · 每次通关 / 失败 / 领取奖励都会立即写入浏览器本地存储
  · 刷新页面、关闭浏览器都不会丢失
  · 阶梯页顶部有绿色「进度已自动保存 · 时:分」指示，一眼可确认
  · 若浏览器禁用了本地存储（隐私模式等），指示会变红并提示进度不会留存
  · 想重来：点「放弃并重来」，会二次确认后清空存档

【动画与特效说明】
  · 卡牌 3D 倾斜跟随鼠标 + 流光反光
  · 手牌扇形排列，新抽牌有入场动画
  · 攻击光束 / 命中爆闪 / 浮动伤害数字 / 归虚·层级提升特效
  · 爬塔：攀升进度条充能、通关金光涟漪、层级符号发光、战利品逐张浮现
  · 界面切换过渡、滚动渐显、按钮流光与波纹、流星背景
  · 入场按元素语义差异化：卡牌缩放弹入、阶梯左右交替（像盘旋而上）、节点自下浮起，
    不是整屏共用一种淡入
  · 首页按节奏编排依次落位，主标题带渐变流光
  · 系统开启「减弱动态效果」时自动关闭动画（无障碍支持）

【序章·教学模式（新手必看）】
  · 首页点「序章」进入，共 7 课：存在度 → 算力Ψ → 战吼/亡语 → 层级压制(归虚) → 锐化/结构
    → 后继差 → 毕业考核。每课逐步解锁新卡、递增难度，通关后解锁下一课。
  · 第 1 课是手把手教学：金色高亮环 + 气泡逐步提示你点
    「手牌 → 空槽召唤 → 我方单位 → 敌方英雄 → 结束回合」，点错不惩罚，多练几回合直到通关。
  · 第 2~7 课是目标引导：顶部常驻「本关目标」条，达成时飘字确认；关键牌带「本课重点」金标。
  · 进度自动保存，随时回来继续；全部结业后首页会显示「已结业」徽章，可「重新学习」。

祝游玩愉快。

【界面与交互（本版重点重做）】
  · 五个主页面（首页 / 学院 / 对战 / 阶梯 / 图鉴 / 规则 / 组牌）各有专属页头横幅，
    横幅插画全部内联，单文件版双击即可显示。
  · 对战界面重排：战场上/下两排贴中线，中间是「后继天平」——12 格刻度 + 双方读数，
    接近 12 时数字会发烫闪烁，胜负进度一眼可见。
  · 指定目标时不再只有一句提示：顶部横幅显示可选目标数量，所有合法目标会脉冲高亮。
  · 空战场有引导文字；我方回合顶栏出现「第 N 回合 · 轮到你了」徽章；
    底部操作条在回合初只给「结束回合」，出过牌之后才出现「幂集跃迁」。
  · 竖屏手机（≤560px）：顶栏压成一行（导航可横滑，长名字自动用「学院 / 阶梯」短标签），
    回合徽章挪到导航下方，省下约 60px 全给战场；场上的牌改成「插画条 + 两行名字 + 攻血」，
    68px 宽的窄卡里不再塞 8px 正文（正文请看详情弹窗），一眼就能认出是谁。
  · 窄屏（≤900px）：英雄条改网格布局，算力用 Ψ 12/12 数字表示，操作条收进底部流内，
    手牌只保留「名字 / 类型 / 攻血」，卡名最多两行；提示条落在手牌上沿，不遮挡信息。
  · 横屏手机 / 矮窗口（高度 ≤560px）：顶栏压成一行、战场小卡按剩余高度自动缩放、
    手牌压到 92px（不再扇形叠压，每张牌名字都完整）、天平压到 30px，提示条落到左下角空位，
    整套战场一屏可见；学院 / 阶梯 / 图鉴 / 组牌的横幅也收成一条，首屏就能看见第一层与卡池。
  · 组牌器：卡池按层级分组并给出分组计数，筛选栏分成「搜索 / 卡型 / 层级」三行，
    筛不到结果时给出可点的「重置筛选」。
  · 选牌组界面直接展示每套预组的 3 张代表卡面（悬停会轻微展开）。
  · 规则书顶部新增 4 个关键数值速览（Ψ 12 / +2 层 / 2Ψ / 12），规则条目带编号。
  · 卡牌插画扩到 30 张：三套预组的主力卡（自然数集的牧者 / 实数之海 / 不可数集 / 连续统之影 /
    β序数 / 不可达基数 / 递归套娃 / 区间之实 / 算力矿井 / 信息碑）都补了专属画面。
  · 教学引导条在窄屏不会换行挤掉战场：课次 + 步骤 + 一枚「本关目标」按钮，点一下才展开目标全文。

【本版优化与开发自检】
  · 适配手机窄屏与横屏：导航可横向滑动，战场、手牌、操作按钮按视口收缩，并处理刘海屏安全区。
  · 支持键盘操作：可点击卡片可通过 Tab 定位、Enter / 空格触发；弹窗支持焦点管理与 Esc 关闭。
  · 页面尊重系统「减少动态效果」设置；切到后台时暂停星尘动画，降低耗电与无效绘制。
  · 图片、CSS 与 JavaScript 均为本地资源；独立版可重新生成：node build.js。
  · 目标牌会先校验合法目标；没有目标或目标失效时不会误扣手牌、算力或操作次数；双杀判平局。
  · 「可测基数」现在会让玩家从检视的牌中亲自选择；「无限时间图灵机」抽到实体牌时显示并保留该牌的 +1 层级。
  · 开发自检（无需第三方依赖）：node --test tests/*.test.js
  · 本地预览：python3 -m http.server 8080，然后访问 http://localhost:8080。
